# Abyssal Cartographer

An original dark Omarchy theme charting an impossible ocean through cyan sonar, cold metal, and bioluminescent map lines.

![Abyssal Cartographer desktop preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/leaflessbranch/omarchy-abyssal-cartographer-theme.git
```

Switch between the two included wallpapers with `omarchy theme bg next`. Update all Git-installed themes with `omarchy theme update`, or remove this one with `omarchy theme remove abyssal-cartographer`.

Requires a current Omarchy installation. Developed and tested with Omarchy 4.0.0-1.

## Included

- Complete dark palette generated through `colors.toml`
- Two original 16:9 wallpapers
- Coordinated Omarchy lock-screen colors
- Transparent Plymouth unlock emblem and preview
- `Yaru-prussiangreen-dark` icon selection

Part of [Omarchy Dreamscapes](https://github.com/leaflessbranch/omarchy-dreamscapes), a ten-theme surreal desktop collection.
